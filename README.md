
---

## ▶️ Como Executar
1. Clone ou baixe este repositório.
2. Certifique-se de que todos os arquivos (`index.html`, `style.css`, `script.js`) estejam na mesma pasta.
3. Abra o arquivo `index.html` em qualquer navegador moderno.
4. Veja as animações acontecendo ao carregar a página e interagir com os elementos.

---

## 📦 Dependências
- [GSAP](https://greensock.com/gsap/) (importado via CDN no `index.html`)

---

## 🔧 Possíveis Extensões
- Substituir GSAP por [Anime.js](https://animejs.com/) para comparar abordagens.
- Adicionar mais elementos interativos (cards de produtos, carrossel de imagens).
- Integrar com backend para simular carrinho de compras real.

---

## 🖼️ Demonstração
Ao abrir a página:
- O título e a descrição deslizam suavemente para aparecer.
- A imagem gira levemente.
- O botão "Adicionar ao carrinho" pulsa continuamente para chamar atenção.
